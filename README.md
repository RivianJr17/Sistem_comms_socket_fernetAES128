Repo ini merupakan Praktik Kerja Lapangan dengan judul

"SIMULASI SISTEM KOMUNIKASI KENDALI MENGGUNAKAN SOCKET PROGRAMMING DENGAN KEAMANAN ENKRIPSI FERNET"

fernet_key.key merupakan kunci enkripsi fernet yang telah ditentukan

server.py merupakan server yang bekerja sebagai perantara bagi client

utils.py merupakan utility code yang dibutuhkan dalam sistem

chat_gui.py merupakan sistem komunikasi untuk client yang telah dilengkapi dengan ui dari tkinter
